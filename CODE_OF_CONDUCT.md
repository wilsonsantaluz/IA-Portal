# Community conduct

We aim for a welcoming engineering community. Be respectful, specific and
constructive. Critique ideas and code rather than people. Make room for different
backgrounds, abilities, experience levels and languages.

Harassment, threats, discrimination, unwanted sexual attention, repeated personal
attacks, sharing another person's private information and publishing credentials
or private customer/employer material are unacceptable. Do not pressure others
to disclose personal information or credentials to reproduce an issue.

These expectations apply to repository issues, pull requests, reviews and other
project-managed spaces. Maintainers may edit/remove inappropriate content, ask
participants to change behavior, restrict participation or remove access in
proportion to the conduct. Decisions should consider context and confidentiality.

For a private report, use a maintainer-provided private channel; if none is listed,
request one without naming affected people publicly. Security reports follow
[SECURITY.md](SECURITY.md). The project currently has no dedicated conduct team,
published response SLA or independent appeal body; do not imply otherwise.
